# 微信交付排版 SOP（WeChat Delivery SOP）

> 适用范围：所有经微信 bot 渠道的交付（消息回复、文档生成）。
> 微信不渲染 Markdown——**一切发给用户的消息必须是纯文本**，一切文档必须真正排版。

## 1. 回复消息：纯文本铁律（违反 = 交付降级）

微信显示的是原始字符，以下 Markdown 标记会原样泄漏给用户，**禁止**出现在回复中：

| 禁止 | 示例（错误） | 正确写法 |
|------|--------------|----------|
| 加粗星号 | `文件大小 **42 KB**` | `文件大小 42 KB` |
| 行内代码反引号 | 位于 `outputs/简历.docx` | 位于 outputs/简历.docx |
| 标题井号 | `# 排版要点` | `排版要点` |
| 删除线 | `~~旧方案~~` | `旧方案（已废弃）` |
| md 链接 | `[下载](https://…)` | 直接给 URL：https://… |

允许且鼓励的纯文本排版手段：

- 序号列表：`1.` `2.` 或 `- `（微信正常显示）
- 分段空行（重要：微信消息里空行 = 视觉分隔）
- Emoji 强调：`✅` `📄` `⚠️`（不要用符号堆砌，克制使用）
- 关键信息放**最前面**（微信会折叠长消息）

## 2. 文档生成：先本地 pandoc，再 python-docx

工具链（runner 镜像内置，**本地直接执行**）：

- **pandoc**：md → docx/pdf/html 等格式转换。用法：
  `pandoc 输入.md -o outputs/输出.docx`
  追求更精细样式时生成 reference-doc 模板再转换：
  `pandoc -o /tmp/ref.docx --print-default-data-file reference.docx`
  `pandoc 输入.md -o outputs/输出.docx --reference-doc=/tmp/ref.docx`
- **python-docx**：需要完全自定义排版（封面、主题色、页眉页脚、表格底纹）时用脚本生成。
- openpyxl（Excel）/ pypdf（PDF 合并拆分）同属镜像能力。

**不要用 `pandoc__*` MCP 工具**：它运行在隔离沙箱，无法读写你的工作区文件（平台已于 2026-08-08 移除该注册）。

**排版质量门槛**（交付前自检）：

1. 文档有明确标题层级（封面/大标题 → 章节 → 小节），不是一坨正文
2. 长文有目录或章节编号，读者能快速定位
3. 表格有表头样式（底纹/加粗），不是光秃秃的网格
4. 中文字体明确设置（微软雅黑/等线/楷体），不是默认宋体
5. 生成后**实际打开验证**（如用 python-docx 重新读取统计段落/表格数，或转 PDF 检查页数），不能只看脚本"跑成功了"

## 3. 交付清单（消息 + 文件）

- 回复文本：先结论后细节；文件路径用 outputs/ 相对路径描述，不带反引号
- 文件：统一输出到 `outputs/` 目录，文件名用中文可读名（如 `简历与面试准备指南.docx`）
- 文件 + 文字同时交付时：文字说明文档内容、格式、大小；不要只丢一个文件名
- 多条消息合并的场景：微信会把"文件+文字"拆成多条入站，聚合后任务里同时有 text 和 media_paths——**必须两者都处理**（文字是意图，文件是素材），不得只处理其一

## 3.5 图片交付约束（2026-08-14 生产实证，微信 C2C CDN 节流）

- 交付链会自动把**超限静态图**（png/jpeg/webp/bmp >300KB）转 JPEG 压缩到 ≤300KB 再发——用户无感，**不要手动重复压缩**；动图（GIF）不转换。
- **生成端控制（更重要）**：本服务器（海外）→微信 CDN 实测限速 ~18KB/s，**>~450KB 的图片上传必失败**。生图默认 1024x1024 即可；如需大图，用 `size` 参数控制输出，避免产出 >1MB 的静态图。
- 动图/视频/大文件（>500KB）交付仍受 CDN 节流限制——优先用文档（docx/pdf）承载，避免必须发大图/视频。
- 文本中提及图片时用 `[FILE:outputs/xxx.png]` marker（交付链解析后以图片消息发出），不要只写路径文字。

## 4. 反例与正例

错误回复（md 泄漏）：

```
任务完成：Word 文档已生成成功！文件大小 **42 KB**，位于 `outputs/简历.docx` ✅
**排版美化要点：**
- 📄 **封面标题**
```

正确回复（纯文本）：

```
任务完成，文档已生成：
文件：简历与面试准备指南.docx（42 KB）
- 封面大标题 + 副标题
- 深蓝主题色章节标题
- 等级表格 + 引用块排版
- 页脚页码

直接点击上方文件即可下载。
```

---

**自检清单**（交付前过一遍）：回复无 `**` / 反引号 / `#`；文档真排版且已验证；文件在 outputs/；文字和附件都处理了。
