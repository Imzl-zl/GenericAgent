# 快速修复指南：管理员绑定微信

## 🔴 问题

你遇到 `UNAUTHORIZED: missing Authorization header` 是因为：

- 微信二维码接口需要**用户 Bearer Token**（普通用户登录）
- 你用的是**管理员 Dev Token**（管理后台登录）
- 这两种认证方式不兼容

## ✅ 解决方案

有两种方式：

### 方式 1：创建普通用户并登录（推荐）

#### 步骤 1：重启 Bot Poller

首先修复 Bot Poller 启动错误，关闭当前 Bot Poller 窗口，重新运行：

```powershell
.\start-bot-poller.ps1
```

应该正常启动，不再报 `unrecognized arguments` 错误。

#### 步骤 2：管理员后台创建用户

1. 访问 http://localhost:5173/admin/login
2. 使用管理员凭据登录：
   - 用户名：`admin`
   - Dev Token：`f02adcb48a1eaa121a4e3b6edfdafdb30c860de02492d65de879ed0da9e74149`
3. 进入管理后台后，需要通过 API 创建用户

#### 步骤 3：通过 API 创建用户

在 PowerShell 中运行：

```powershell
# 创建一个测试用户
$headers = @{
    "X-Platform-Dev-Token" = "f02adcb48a1eaa121a4e3b6edfdafdb30c860de02492d65de879ed0da9e74149"
    "Content-Type" = "application/json"
}

$body = @{
    username = "testuser"
    password = "test123456"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:8080/v1/admin/users" -Method POST -Headers $headers -Body $body
```

返回结果类似：
```json
{
  "user_id": 2,
  "username": "testuser",
  "status": "pending",
  "created_at": "2026-07-26T..."
}
```

#### 步骤 4：批准用户

```powershell
# 批准刚创建的用户（假设 user_id 是 2）
Invoke-RestMethod -Uri "http://127.0.0.1:8080/v1/admin/users/2/approve" -Method POST -Headers $headers
```

#### 步骤 5：用户登录并绑定微信

1. **退出管理员登录**：访问 http://localhost:5173 并点击右上角退出
2. **普通用户登录**：访问 http://localhost:5173/login
   - 用户名：`testuser`
   - 密码：`test123456`
3. 登录成功后，点击"微信绑定"
4. 点击"获取二维码" - **现在应该成功了！**
5. 用微信扫码并确认
6. 在微信给 Bot 发消息测试

### 方式 2：修改代码让管理员也能绑定（需要改代码）

如果你希望管理员账号也能直接绑定微信，需要修改后端代码：

#### 修改 `admin.go`

将微信二维码路由改为同时支持 `auth` 和 `userAuth`：

```go
// 在 registerLifecycleRoutes() 中：
if s.wechatBinding != nil {
    // 普通用户路由
    s.mux.HandleFunc("POST /v1/users/me/wechat-qrcode", s.userAuth(s.handleCreateWechatQRCode))
    s.mux.HandleFunc("GET /v1/users/me/wechat-qrcode/status", s.userAuth(s.handleGetWechatQRCodeStatus))
    
    // 管理员路由（新增）
    s.mux.HandleFunc("POST /v1/admin/me/wechat-qrcode", s.auth(s.handleAdminCreateWechatQRCode))
    s.mux.HandleFunc("GET /v1/admin/me/wechat-qrcode/status", s.auth(s.handleAdminGetWechatQRCodeStatus))
}
```

但这需要重新编译和测试，不推荐初次使用时这么做。

## 🆘 如果还有问题

### 问题：创建用户失败

**可能原因**：数据库未初始化或连接失败

**解决**：
```powershell
# 检查数据库是否运行
docker ps | grep postgres

# 查看 Backend 日志，应该有数据库连接成功的信息
```

### 问题：用户登录失败

**可能原因**：用户状态不是 `approved`

**解决**：
```powershell
# 再次批准用户
$headers = @{
    "X-Platform-Dev-Token" = "f02adcb48a1eaa121a4e3b6edfdafdb30c860de02492d65de879ed0da9e74149"
}
Invoke-RestMethod -Uri "http://127.0.0.1:8080/v1/admin/users/2/approve" -Method POST -Headers $headers
```

### 问题：扫码后没有反应

**检查清单**：
- ✅ Bot Poller 是否正在运行？
- ✅ Backend 日志是否显示调用了 `/start`？
- ✅ 微信是否安装了 ClawBot 插件？

## 🎯 总结

**核心区别**：

| 登录方式 | 认证方式 | 能否绑定微信 | 用途 |
|---------|---------|------------|-----|
| 管理员登录 (`/admin/login`) | X-Platform-Dev-Token | ❌ 不能 | 管理后台、用户审批 |
| 普通用户登录 (`/login`) | Bearer Token | ✅ 能 | 绑定微信、使用 AI 助手 |

**现在要做的**：
1. 重启 Bot Poller（修复启动参数）
2. 创建普通用户 `testuser`
3. 用 `testuser` 登录
4. 绑定微信

就是这样！
