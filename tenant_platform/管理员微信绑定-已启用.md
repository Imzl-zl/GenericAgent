# ✅ 管理员微信绑定功能已启用

## 修改内容

已经为管理员添加了微信绑定功能，现在管理员和普通用户都能绑定微信。

### 后端修改

1. **新增管理员专用 API**：
   - `POST /v1/admin/me/wechat-qrcode` - 管理员获取二维码
   - `GET /v1/admin/me/wechat-qrcode/status` - 管理员轮询扫码状态

2. **使用开发者 user_id**：
   - 管理员绑定的微信会关联到 `.env` 中配置的 `PLATFORM_DEV_USER_ID`
   - 默认是用户 ID 1（admin 用户）

### 前端修改

1. **API 客户端**：
   - 添加 `createAdminWechatQRCode()` 和 `getAdminWechatQRCodeStatus()`
   - 根据 `isAdmin` 标志自动调用对应的 API

2. **管理员导航**：
   - 在管理后台侧边栏添加"微信绑定"入口
   - 路由：`/admin/binding`

3. **BindingPage 组件**：
   - 自动检测用户类型（管理员 vs 普通用户）
   - 调用对应的 API 接口

## 🚀 如何使用

### 步骤 1：重启服务

**重要**：必须重启后端和前端服务才能生效！

#### 重启后端

关闭当前 Backend 窗口，重新运行：

```powershell
.\start-backend.ps1
```

启动日志应该显示：
```

platform: bot poller transport url=http://127.0.0.1:8081 webhook=http://127.0.0.1:8080/v1/im/webhook
```

#### 重启前端

关闭当前 Web 窗口，重新运行：

```powershell
.\start-web.ps1
```

#### 重启 Bot Poller（如果还没重启）

关闭当前 Bot Poller 窗口，重新运行：

```powershell
.\start-bot-poller.ps1
```

应该正常启动，不再报错。

## 🎯 技术细节

### 认证流程对比

| | 管理员 | 普通用户 |
|---|---|---|
| 登录接口 | `/admin/login` | `/login` |
| 认证方式 | X-Platform-Dev-Token | Bearer Token |
| 二维码接口 | `/v1/admin/me/wechat-qrcode` | `/v1/users/me/wechat-qrcode` |
| 状态接口 | `/v1/admin/me/wechat-qrcode/status` | `/v1/users/me/wechat-qrcode/status` |
| 绑定的 user_id | `PLATFORM_DEV_USER_ID`（默认 1） | 登录用户的实际 user_id |

### 数据库记录

绑定成功后，数据库中会创建：

1. **wechat_qr_sessions 表**：
   - 记录扫码会话
   - `user_id` = 1（管理员）
   - `status` = 'confirmed'
   - 包含加密的 `bot_token_ciphertext`

2. **bots 表**：
   - 记录 Bot 信息
   - `owner_id` = 1（管理员）
   - `ilink_bot_id` 和 `ilink_user_id`
   - `state` = 'active'

## ❓ 常见问题

### Q1: 修改后还是报 404 或 UNAUTHORIZED？

**原因**：后端或前端没有重启

**解决**：
1. 关闭所有服务窗口
2. 按顺序重启：PostgreSQL → Bot Poller → Backend → Frontend

### Q2: 前端页面没有"微信绑定"入口？

**原因**：前端代码没有热重载，或缓存问题

**解决**：
1. 强制刷新浏览器（Ctrl + Shift + R）
2. 或清除浏览器缓存
3. 或重启前端服务

### Q3: 扫码后没反应？

**检查**：
- ✅ Bot Poller 是否正在运行？
- ✅ Backend 日志是否显示调用了 Bot Poller 的 `/start`？
- ✅ 微信是否安装了 ClawBot 插件？

### Q4: 管理员和普通用户都绑定了，消息会发给谁？

**答案**：每个用户有独立的 Bot，消息发给对应的 Bot owner。

- 管理员的微信消息 → 管理员的任务
- 普通用户的微信消息 → 普通用户的任务

它们是完全隔离的。
