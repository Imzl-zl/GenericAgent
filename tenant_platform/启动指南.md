## 🚀 快速启动

### 方式 1：一键启动所有服务（推荐）

```powershell
cd tenant_platform
.\start-dev.ps1
```

这会自动启动：
- ✅ PostgreSQL（Docker）
- ✅ Bot Poller（Python）
- ✅ Backend（Go）
- ✅ Web Frontend（React）

### 方式 2：手动逐个启动

#### 1. 启动 PostgreSQL
```powershell
cd infra/postgres
docker compose up -d
```

#### 2. 启动 Bot Poller
```powershell
.\start-bot-poller.ps1
```

#### 3. 启动后端
```powershell
.\start-backend.ps1
```

#### 4. 启动前端
```powershell
.\start-web.ps1
```

### 验证启动成功

打开浏览器访问：
- **前端界面**：http://localhost:5173
- **后端 API**：http://127.0.0.1:8080（无可视化界面）
- **Bot Poller**：http://127.0.0.1:8081（无可视化界面）

## 🔧 服务说明

### 1. PostgreSQL（端口 5432）

**作用**：存储所有平台数据

- 用户账号、权限
- 微信 Bot Token（加密）
- 任务记录和会话历史
- LLM Provider 配置

**配置**：`infra/postgres/.env`

**数据持久化**：`infra/postgres/data/`

### 2. Bot Poller（端口 8081）

**作用**：微信消息收发的桥梁

**关键功能**：
- `/start` - 注册一个新 Bot 开始轮询（由 Backend 调用）
- `/send` - 发送消息到微信（由 Backend 调用）
- `/stop` - 停止 Bot 轮询（由 Backend 调用）
- 主动推送：收到微信消息后 POST 到 `PLATFORM_WEBHOOK_URL`

**启动命令**：
```bash
python poller_server.py \
  --listen=127.0.0.1:8081 \
  --webhook-url=http://127.0.0.1:8080/v1/im/webhook \
  --api-secret=dev-secret-change-in-production \
  --media-dir=./runtime/bot_media
```

**日志输出**：
- 启动成功会显示监听地址
- 收到消息会显示消息内容和转发状态
- 发送消息会显示发送结果

### 3. Platform Backend（端口 8080）

**作用**：平台核心业务逻辑

**关键端点**：
- `POST /v1/register` - 用户注册
- `POST /v1/login` - 用户登录
- `POST /v1/users/me/wechat-qrcode` - 生成微信登录二维码（你遇到 404 的接口）
- `GET /v1/users/me/wechat-qrcode/status` - 轮询扫码状态
- `POST /v1/im/webhook` - 接收 Bot Poller 转发的微信消息
- `POST /v1/admin/*` - 管理员接口（需要 `X-Platform-Dev-Token`）

**启动参数**：
```bash
go run ./cmd/platform/main.go \
  --listen=127.0.0.1:8080 \
  --database-url="postgresql://..." \
  --bot-token-key="..." \
  --ilink-base-url="https://ilinkai.weixin.qq.com" \
  --bot-poller-url="http://127.0.0.1:8081"
```

### 4. Web Frontend（端口 5173）

**作用**：用户和管理员的 Web 界面

**功能页面**：
- `/login` - 普通用户登录
- `/admin/login` - 管理员登录
- `/app/binding` - 微信绑定页面（生成二维码）
- `/app/dashboard` - 用户仪表板
- `/admin/*` - 管理后台

## 💬 完整微信功能配置

### 配置清单

`.env` 文件中需要配置以下所有项目：

```bash
# ✅ 必需 - iLink 官方服务器
ILINK_BASE_URL=https://ilinkai.weixin.qq.com
ILINK_APP_ID=bot
ILINK_CLIENT_VERSION=2.1.1

# ✅ 必需 - Bot Poller 配置
BOT_POLLER_URL=http://127.0.0.1:8081
BOT_POLLER_API_SECRET=dev-secret-change-in-production
PLATFORM_WEBHOOK_URL=http://127.0.0.1:8080/v1/im/webhook

# ✅ 必需 - 加密密钥
BOT_TOKEN_KEY=6ece3dfc8f772ffa08c0d6b4a0e4331179a1219222dfb94465a4379e558b17c4
```

### 工作流程

#### 1. 微信扫码登录

```
用户点击"获取二维码"
  ↓
前端调用: POST /v1/users/me/wechat-qrcode
  ↓
Backend 调用: iLink GET /ilink/bot/get_bot_qrcode?bot_type=3
  ↓
iLink 返回: {qrcode: "...", qrcode_img_content: "data:image/png;base64,..."}
  ↓
前端显示二维码
  ↓
用户微信扫码确认
  ↓
前端轮询: GET /v1/users/me/wechat-qrcode/status?qrcode_token=...
  ↓
Backend 调用: iLink GET /ilink/bot/getQRCodeStatus?code=...
  ↓
iLink 返回: {status: "confirmed", bot_token: "...", ...}
  ↓
Backend 加密存储 bot_token，创建 Bot 记录
  ↓
Backend 调用: Bot Poller POST /start
  ↓
Bot Poller 开始长轮询 iLink
```

#### 2. 接收微信消息

```
用户在微信发送消息
  ↓
iLink 服务器接收
  ↓
Bot Poller 长轮询获取: iLink POST /ilink/bot/getUpdates
  ↓
Bot Poller 下载媒体文件（如果有）
  ↓
Bot Poller 转发: POST http://127.0.0.1:8080/v1/im/webhook
  {
    "bot_uuid": "...",
    "sender_id": "...",
    "text": "...",
    "media_assets": [...]
  }
  ↓
Backend 创建任务，分配到 Worker
  ↓
Worker 执行 GenericAgent
  ↓
Worker 返回响应
  ↓
Backend 调用: Bot Poller POST /send
  {
    "bot_uuid": "...",
    "to_user": "...",
    "msg_type": "text",
    "text": "..."
  }
  ↓
Bot Poller 调用: iLink POST /ilink/bot/sendMessage
  ↓
用户微信收到回复
```

## ❓ 常见问题

### Q1: 点击"获取微信二维码"返回 404 Not Found

**原因**：`.env` 文件中缺少 `ILINK_BASE_URL` 配置，导致后端没有注册微信相关路由。

**解决**：确保 `.env` 中有以下配置：
```bash
ILINK_BASE_URL=https://ilinkai.weixin.qq.com
ILINK_APP_ID=bot
ILINK_CLIENT_VERSION=2.1.1
```

然后重启后端：
```powershell
# 关闭当前后端窗口，重新运行：
.\start-backend.ps1
```

启动日志中应该看到：
```
platform: wechat qr binding enabled base_url=https://ilinkai.weixin.qq.com
```

### Q2: 扫码成功但收不到微信消息

**原因**：Bot Poller 未启动，或配置错误。

**检查步骤**：

1. 确认 Bot Poller 正在运行：
   ```powershell
   # 应该有一个窗口运行 poller_server.py
   # 或者查看进程：
   Get-Process python | Where-Object {$_.CommandLine -like "*poller_server*"}
   ```

2. 检查 `.env` 配置：
   ```bash
   BOT_POLLER_URL=http://127.0.0.1:8081
   PLATFORM_WEBHOOK_URL=http://127.0.0.1:8080/v1/im/webhook
   ```

3. 查看 Bot Poller 日志，应该有类似输出：
   ```
   Bot Poller listening on 127.0.0.1:8081
   Registered bot abc123, starting poll loop...
   ```

4. 查看 Backend 日志，绑定成功后应该调用了 `/start`：
   ```
   Calling Bot Poller: POST http://127.0.0.1:8081/start
   Bot started successfully
   ```

### Q3: Bot Poller 启动失败：ModuleNotFoundError

**错误**：
```
ModuleNotFoundError: No module named 'Crypto'
```

**解决**：安装依赖
```bash
pip install pycryptodome requests
```

### Q4: 如何验证整个流程是否正常？

**测试步骤**：

1. ✅ 确认 4 个服务都在运行：
   - PostgreSQL（Docker）
   - Bot Poller（Python 窗口）
   - Backend（Go 窗口）
   - Frontend（npm 窗口）

2. ✅ 访问 http://localhost:5173，使用 `admin` / `f02adcb...` 登录

3. ✅ 点击"微信绑定"页面，点击"获取二维码"
   - 应该立即显示二维码
   - 不应该报 404 错误

4. ✅ 用微信扫码（需要安装 ClawBot 插件）
   - 扫码后点击确认
   - 前端应该显示"已绑定"

5. ✅ 在微信给 Bot 发送消息
   - Bot Poller 日志应该显示收到消息
   - Backend 日志应该显示创建任务
   - 几秒后微信应该收到回复

### Q5: 生产环境部署需要改什么？

**必须修改**：

1. **PLATFORM_DEV_TOKEN** - 生成强随机密码
   ```bash
   openssl rand -hex 32
   ```

2. **BOT_POLLER_API_SECRET** - 生成强随机密码
   ```bash
   openssl rand -hex 32
   ```

3. **BOT_TOKEN_KEY** - 使用安全的密钥管理服务

4. **数据库密码** - 不要使用示例密码

5. **监听地址** - 生产环境不应该绑定 127.0.0.1

6. **HTTPS** - 生产环境必须使用 HTTPS
